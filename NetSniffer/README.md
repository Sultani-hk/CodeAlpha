# NetSniffer 

A simple, lightweight network packet sniffer written in python using the 
*** Scapy ** library. 
This script capture network traffic , count the packets , 
and logs the source IP addresses of the incoming packets.

## Disclaimer 

** This tool is for educational and ethical testing purposes only .**
Do not use this tool on networks you do not own or have expicit permission to test.
Unauthorized network sniffing is illegal.

### Features 

* Captures live network packets.
* Filters adn displays the source IP address of IPv4 packets.
* Keeps a running count of total packets captured.
* Clean output fomatting with timestamps.
* Graceful exit when interrupted (Crl+C)

### Perequisites 
*** Python 3.x ** installed 
* *** kali Linux ** (or any Linux distribution ).
* ** Root privileges**
